# ドメイン策定

ドメインを整理・把握・決定するためのもの。

## ドメインの説明

ゲストでも閲覧できる記事投稿プラットフォーム。

## イメージ

画面を想像してこんなものがあるよなぁと考えたもの。\
ドメインエンティティではない。網羅的でもない。

### アカウント

- 名前
- 自己紹介

### 記事

- タイトル
- タグリスト
- アカウント
- 投稿日時
- 編集日時
- 内容
- コメントリスト
- いいね数

### コメント

- アカウント
- 投稿日時
- 編集日時
- 内容
- いいね数

## 機能

ユースケース相当だが入出力までは考えない。\
ゲストの記事閲覧は公開状態のもののみ。\
認証はOIDCのIdP担当する。

### 全ユーザー利用可能

- 特定記事の閲覧
- 記事を一覧
  - 投稿日時順
  - いいね数順
- 検索して記事を一覧
  - 検索対象: タイトルと内容
  - 投稿日時順
  - いいね数順
- 特定タグの記事を一覧
  - 投稿日時順
  - いいね数順
- 特定アカウントのプロフィールを閲覧
- 特定アカウントの記事を一覧
  - 投稿日時順
  - いいね数順

### 認証済みかつアカウントなしユーザー専用

- 指定したアカウントIDの利用可否確認
- アカウントIDを指定してアカウント登録(プロビジョニング)

### 認証済みかつアカウントありユーザー専用

- 自分のアカウントを更新
- 自分のアカウントを削除
- 自分の記事を一覧
  - 状態フィルター可能
  - 投稿日時順
  - いいね数順
- 自分の記事を投稿
- 自分の記事を編集
- 自分の記事を削除
- 自分の記事の特定コメントを削除
- コメント可能公開記事へのコメント
- 自分のコメントを編集
- 自分のコメントを削除
- 記事にいいね
- 過去に記事へしたいいね解除
- 自分がいいねした記事を一覧
  - いいねした順
- コメントにいいね
- 過去にコメントへしたいいね解除

所謂ログアウトはクライアントとIdPの間で行うので当APIの機能ではない。

## エンティティと基本ルール

文字列属性は基本的に正規化済みとする。正規化: 制御文字除去、Unicode正規化、前後空白のトリム。\
文字数はグラフィーム単位で数える。\X{m,n}はm文字以上n文字以下のこと。\
日時は西暦UTCで年月日時分秒ミリ秒まで表現できること。

### アカウント

| 属性                  | フォーマット         | 変更 | その他ルール                                                                                  |
| --------------------- | -------------------- | ---- | --------------------------------------------------------------------------------------------- |
| ID                    | `[a-zA-Z0-9_]{3,20}` | 不可 |                                                                                               |
| IdPサブジェクト識別子 | OIDC仕様に従う       | 不可 | アカウント全体で一意                                                                          |
| 名前                  | `\X{1,20}`           | 可   | 改行を含まない。デフォルト: フォーマットに適合する場合はIdPのnameクレーム値、その他は"user"。 |
| 自己紹介              | `\X{0,100}`          | 可   |                                                                                               |
| 作成日時              |                      | 不可 | エンティティ発生日時                                                                          |
| 更新日時              |                      | 可   | 作成日時と同じか後                                                                            |

## その他のルール

### エンティティ種類横断

- 親エンティティを削除すると子エンティティは全て削除される
- アカウントあたりの記事数は全状態合計で10_000まで
- 記事系の状態遷移
  - 下書き → 公開
  - 公開 → 非公開
  - 非公開 → 公開
  - 遷移時に(公開時)コメント可否を引き継ぐ
- 1記事あたりのタグ数は10個まで
- 各種いいねは1アカウント1対象1つまで
- コメントの削除はコメントの所有者か、対象記事の所有者に限る

### レートリミット

- 記事の作成は1分間に1つまで
  - スパム的行動を回避するため
- 同一記事へのコメントは1分間に1つまで
  - スパム的行動を回避するため
- その他リミットは機能ごとに大雑把なもので、詳細は未定

### その他

- アプリのアカウント削除時、IdPのアカウントは残す
- 未認証ユーザーが認証済みユーザー専用機能を利用した場合、未認証エラーを返す
- 認証済みかつアカウントなしユーザーが、認証済みかつアカウントありユーザー専用機能を利用した場合、アカウント未作成エラーを返す
- 認証済みかつアカウントありユーザーが、認証済みかつアカウントなしユーザー専用機能を利用した場合、アカウント作成済みエラーを返す
